IntelliDocs Story Board

Figure 29–35: Storyboard for IntelliDocs presenting the full user experience through a sequence of visual screens, from landing page and authentication through document management and the editor.

Storyboard narrative (from the manuscript): It begins with the user visiting the landing page and proceeding to either sign in to an existing account or register a new one. From there, the user is directed to the dashboard where they can view recent document activity, manage storage, and create or import documents. The storyboard then shows how users navigate their document library through the Recent Documents and My Documents screens, where confidence score indicators provide a quick overview of how well the system has learned their formatting habits. It further illustrates the core editing experience inside the Document Editor, where the system displays inline formatting suggestions with visible confidence scores derived from the user's behavioral learning profile, and where the Gemini AI assistant panel is available for natural language formatting queries. Finally, the storyboard covers the Trash screen, showing how users can manage and recover recently deleted documents before permanent removal.

Screen 7 Document Editor Figure 34

Module Type

Document Editor Module. This is the core screen of IntelliDocs. It provides a custom contentEditable document editor with a full formatting toolbar. Inline confidence score suggestions appear directly on the text. The Gemini AI assistant panel is accessible on the right side for user-directed formatting queries and natural language commands.

Items

ItemsTypeRequired?Data TypeSize
Formatting ToolbarToolbarNoN/AN/A
Content Editor AreaTextboxYesTEXTN/A
Inline SuggestionBadge / DisplayNoN/AN/A
Confidence ScoreDisplayNoN/AN/A
Gemini AssistantPanelNoN/AN/A
Ask Gemini InputTextboxNoVARCHAR500
Export ButtonButtonNoN/AN/A
Auto-Save StatusDisplayNoN/AN/A

Logic

  1. The user opens or creates a document and is directed to the editor screen.
  2. The system loads the document content and formatting history.
  3. As the user types, the BehaviorListener captures formatting actions in real time.
  4. The ML model analyzes the text context and generates a formatting suggestion with a confidence score.
  5. The suggestion is displayed inline directly on the relevant text.
  6. The user accepts the suggestion by pressing Tab or rejects it by pressing Escape.
    • If accepted, the formatting is applied and the action is logged to the behavioral pipeline.
    • If rejected, the rejection is logged as a negative training signal.
  7. The system auto-saves the document content periodically via Supabase Realtime.
  8. The user may open the Gemini Assistant panel and type a query for AI-assisted formatting.
Screen 8 Trash Figure 35

Module Type

Document Management Module. This screen displays recently deleted documents with the number of days remaining before permanent deletion. Users can restore documents or permanently remove them.

Items

ItemsTypeRequired?Data TypeSize
Deleted DocumentsListNoN/AN/A
Days RemainingDisplayNoN/AN/A
Restore ButtonButtonNoN/AN/A
Permanent DeleteButtonNoN/AN/A

Logic

  1. The system loads all documents deleted by the user that have not yet been permanently removed.
  2. Each deleted document displays the title, deletion date, and remaining days before permanent deletion.
  3. Documents approaching permanent deletion within 24 hours are highlighted with a warning.
  4. The user clicks "Restore" to recover a deleted document.
    • The system moves the document back to the user's document list.
  5. The user clicks the delete icon to permanently remove a specific document.
  6. The user clicks "Empty Trash" to permanently delete all items in the trash.
    • The system prompts the user to confirm before permanently deleting all items.
