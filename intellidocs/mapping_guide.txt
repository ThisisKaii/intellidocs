# IntelliDocs Ignored/Untracked Files Destination Mapping Guide
#
# If you extract the contents of "intellidocs_critical.zip" directly into the root
# of your cloned repository on Windows, all files will automatically land in their
# correct relative locations.
#
# Here is the exact mapping of where the files/directories belong:

[SOURCE PATH IN ZIP]                      -> [DESTINATION PATH IN CLONED REPOSITORY]
--------------------+---------------------------------------------------------------
.agents/                                 -> <repo-root>/.agents/
etc/                                     -> <repo-root>/etc/
graphify-out/                            -> <repo-root>/graphify-out/
ml/models/user_models/                   -> <repo-root>/ml/models/user_models/
frontend/.env.local                      -> <repo-root>/frontend/.env.local
ml/.env                                  -> <repo-root>/ml/.env
server/.env                              -> <repo-root>/server/.env
db/intellidocs_schema.dbml               -> <repo-root>/db/intellidocs_schema.dbml
db/supabase/000_users_reference.sql      -> <repo-root>/db/supabase/000_users_reference.sql
about.md                                 -> <repo-root>/about.md
about2.md                                -> <repo-root>/about2.md

# Windows Automation Commands:
# If you want to automate this using PowerShell, you can run these commands from the repository root:
#
# Expand-Archive -Path "D:\intellidocs\intellidocs_critical.zip" -DestinationPath ".\" -Force

# (Replace "D:\" with your actual USB drive letter on Windows)
